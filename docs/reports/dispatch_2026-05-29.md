## Bell Badge Fix (alerts nav indicator)

Playwright verification found the topbar bell icon had no unacknowledged-alert badge — meaning n8n alert events would be invisible to staff until they thought to click the bell. Fix applied to sandbox branch: added a `nav_alert_count()` Jinja2 template global in `dashboard/app/main.py` (queries `alert_events WHERE acknowledged_at IS NULL`), added badge markup to `dashboard/templates/base.html` (renders only when count > 0), and added `.topbar-alert-badge` CSS + `position: relative` to `.topbar-icon-btn` in `dashboard/static/dashboard.css`. Verified live: badge shows correct count when alerts are present, hidden when zero. Note: the original Playwright finding ("bell badge showed 2") was a misidentification — the "2" was on the sidebar collapse button (correct, shows critical case count for R2 task); the bell had no badge at all. The fix adds the missing bell badge rather than removing an incorrect one.
